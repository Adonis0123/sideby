## 维护者本机只读运行

在维护者真实的 HOME 上只读运行（不加 `--fix`，不改配置；4 个家族共 17 个账号）：`list` 0.12s，`doctor` 0.15s（退出码 0），`quota` 约 1.4–1.9s。这一步发现并修复了两个问题：
- `~/.claude-code-router`（claude-code-router 工具的配置目录）被误认为账号；
- API 账号被显示成「login needed」。

面板在同一个真实 HOME 上打开，账号卡片和额度都能正常显示。具体账号、私人约定和与旧脚本的逐条对照留在维护者本机，不入库。

## UNVERIFIED

- **Claude statusline 的 `rate_limits`**：字段结构来自官方文档（`five_hour` / `seven_day` 下的 `used_percentage`、`resets_at`），实现和测试都按它写，但没有拿真实会话的输入实测过。实测要改主 `settings.json`（`sideby quota setup claude --yes`），这超出了本轮「真实 HOME 只读」的边界。补验方法：作者执行一次 `sideby quota setup claude --yes`，开一个 Claude 会话发一条消息，再运行 `sideby quota claude:main`；不想保留就执行 `sideby quota teardown claude` 还原。
- **Linux**：代码按 macOS 和 Linux 编写（stat 用 Node API，不依赖 BSD 命令），CI matrix 包含 ubuntu-latest，但还没有在 Linux 上实际跑过。仓库推送后由 CI 首跑覆盖。
