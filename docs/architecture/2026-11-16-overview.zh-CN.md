## 组件表

| 名称 | 类型 | 职责 | 代码路径 |
| --- | --- | --- | --- |
| sideby CLI | 入口（Node 可执行文件） | 解析参数，把每个子命令分发到命令函数，只做输入输出 | `src/cli/main.ts`、`src/cli/commands.ts`、`src/cli/args.ts` |
| Panel | 入口（本机 HTTP 服务 + 内联网页） | 在 `127.0.0.1:17420` 展示并操作每个 Account 的健康、Quota、Usage 和 Session | `src/panel/server.ts`、`src/panel/handler.ts`、`src/panel/background.ts`、`src/panel/page.ts` |
| Menu Bar Item | 入口（macOS JXA 脚本，由 LaunchAgent 启动） | 在菜单栏画出 Quota 快照，把点击转成 sideby 命令，自己不读文件不做判断 | `src/menubar/script.ts`、`src/menubar/agent.ts`、`src/menubar/snapshot.ts` |

| Plugin 加载器 | 核心模块 | 加载内置和用户 Plugin，做属主与权限的信任检查，通过 HookBus 运行 Hook | `src/plugins/loader.ts`、`src/plugins/bus.ts`、`src/plugins/account-script.ts` |

| Session 服务 | 核心模块 | 列出 Live Session，维护 History Index，在 Session 之间保存并投递 Message | `src/core/live-sessions.ts`、`src/core/history-index.ts`、`src/core/history.ts`、`src/core/messages.ts` |
| Launch | 核心模块 | 组装只属于一个 Account 的环境和参数，spawn Host；Auto Handoff 时一直当 Host 的父进程 | `src/core/launch.ts`、`src/core/secret-file.ts`、`src/core/session-hooks.ts`、`src/core/handoff-run.ts`、`src/core/handoff-chain.ts` |
| Hook 入口 | 入口（由 Host 运行，不建 Runtime） | `statusline-tap`、`handoff-hook`、`unattended-hook`、`network-hook` 四个命令，只引叶子模块，在会话内读写状态文件或拦截 Host | `src/quota/statusline-tap.ts`、`src/handoff/hook.ts`、`src/unattended/hook.ts`、`src/network/hook.ts` |
| Network Guard | 核心模块 | 经 Host 的代理设置查 Egress 所在国家，不在允许列表就拒绝 Launch | `src/core/egress.ts`、`src/core/network.ts` |
| Update | 核心模块 | 每天至多一次问 npm registry 最新版本，给出 Update Notice，按 Install Method 更新 | `src/core/update.ts` |
| 桌面集成 | 核心模块 | 安装 Dock 图标或 `.desktop` 入口，登录时自启 Panel，按 Account 打开 Desktop App | `src/desktop/app.ts`、`src/core/autostart.ts`、`src/core/desktop-app.ts` |
| sideby 配置 | 本机文件 | 保存 `config.json`（aliases、handoff、unattended、network 等）和用户 Plugin 目录，位置为 `~/.config/sideby/` | `src/core/paths.ts`、`src/core/config.ts` |

## 关系表

| 起点 | 终点 | 动作 | 协议或数据 |
| --- | --- | --- | --- |
| 用户或 AI agent | sideby CLI | 在终端输入命令 | `sideby <命令> [--json]`，退出码 0/1/2/10 |
| 用户或 AI agent | Panel | 用浏览器打开并点击操作 | HTTP，`http://127.0.0.1:17420/`，带 token |
| 用户或 AI agent | Menu Bar Item | 点击图标或按 `⌥X` | macOS 菜单事件 |
| Menu Bar Item | sideby CLI | 每 120 秒启动一次子进程取快照，并把点击转成命令 | `sideby menubar snapshot --json`（NSTask） |
| sideby CLI | Panel | 启动服务，前台或分离成后台进程 | `sideby ui`、`sideby ui --background`（内部 `--serve-detached`） |
| sideby CLI | Runtime | 在命令函数里创建并调用 | 进程内 `createRuntime()` |
| Panel | Runtime | 每个请求通过 `runtimeFactory` 取得并调用 | 进程内方法调用 |
| Portal | Panel | 挂载处理器并传入主题和选项 | `createPanelHandler(options)`，同源 iframe |
| Runtime | sideby 配置 | 读取配置；写 alias 等设置时原子写回 | `config.json`（JSON） |
| Runtime | Plugin 加载器 | 启动时加载全部 Plugin | `loadPlugins({ builtins, config, bus, userPluginsDir })` |
| Plugin 加载器 | sideby 配置 | 读取用户 Plugin 的清单并动态导入入口 | `plugins/<name>/plugin.json`，`import()` |
| Plugin 加载器 | Family Plugins | 调用 `register(api)`，收下每个 FamilyDef | `api.family(def)` |
| Runtime | 账号与 Doctor | 发现 Account、运行检查、应用 Fix、新建 Account | `discoverAccounts`、`runDoctor`、`applyFixes`、`createAccount` |
| 账号与 Doctor | Account 目录 | 读取条目状态，建符号链接或复制，原子写修复 | 文件系统；凭证文件只查类型和 600 权限 |
| Runtime | Quota 与 Usage | 读取每个 Account 的 Quota 和 Usage，给 `sideby next` 排序 | 进程内方法调用 |
| Quota 与 Usage | Family Plugins | 按间隔调用 Family 的读取器 | `FamilyDef.fetchQuota`、quota 和 usage 读取函数 |
| Quota 与 Usage | sideby 状态目录 | 留存每个 Account 最近一次答案，并用锁限制并发 | `quota/<family>/<name>.fetched.json` |
| Family Plugins | Account 目录 | 只读会话记录和登录文件里的身份字段 | Claude `projects/**/*.jsonl`、Codex `sessions/**/rollout-*.jsonl` |
| Family Plugins | Host CLI | 启动 Host 自己的命令问 Quota，不开模型回合 | `claude -p /usage --output-format json`、`codex app-server` 的 `account/rateLimits/read` |
| Family Plugins | sideby 状态目录 | 读取 tap 写下的 Claude 额度缓存 | Claude Quota cache（JSON） |
| sideby CLI | Session 服务 | 列出 Live Session、搜索 Session History、发送 Message，把 Runtime 作为参数传入 | 进程内函数调用（`sessions`、`history`、`send`、`messages` 命令） |
| Panel | Session 服务 | 列出 Live Session 和 Message，从页面发送 Message，把 Runtime 作为参数传入 | 进程内函数调用（`sendMessage`、`listMessages`） |
| Session 服务 | Runtime | 取 Account 列表、Family 表和读取上下文 | `rt.accounts()`、`rt.families`、`rt.readContext()` |
| sideby CLI | Launch | 拿到准备好的启动后运行 Host，Auto Handoff 时交给接力循环 | `runHost(prepared)`、`runWithHandoff(rt, ref, args)` |
| Session 服务 | Family Plugins | 调用各 Host 的会话读取器和投递器 | `liveSessionReader`、`historyReader`、`DELIVERERS` |
| Session 服务 | sideby 状态目录 | 重建并查询 History Index，投递前先保存 Message | SQLite（`node:sqlite`，FTS5）、Message 文件 |
| Runtime | Launch | 为一个 Account 准备启动 | `prepareLaunch(ref, args, command)` |
| Launch | Plugin 加载器 | 启动前运行 `launch.before` Hook，Hook 可改环境或中止 | `bus.run('launch.before', …)` |
| Launch | Account 目录 | 读取 Secret File 并只放进子进程环境 | `proxy.env` |
| Launch | sideby 状态目录 | 写入本次会话的 hook 设置文件；监听 Handoff 的 `ready.json` | Claude `--settings` 文件、`ready.json` |
| Launch | Host CLI | spawn 子进程并继承终端 | 环境变量 `CLAUDE_CONFIG_DIR` / `CODEX_HOME` / `GROK_HOME`、`SIDEBY_ACCOUNT`，Host 参数 |
| Launch | Host CLI | Auto Handoff 时结束旧 Host，再启动下一个 Account | `SIGTERM`（等 10 秒，不强杀），Handoff Brief 的路径 |
| Host CLI | Account 目录 | 读写自己的登录、设置和会话记录 | Host 自有格式 |
| Host CLI | Hook 入口 | 在状态栏刷新、工具调用、回合结束等事件上运行命令 | `sideby statusline-tap`、`sideby handoff-hook`、`sideby unattended-hook`、`sideby network-hook`，stdin JSON |
| Hook 入口 | sideby 状态目录 | tap 写 Claude 额度缓存，handoff-hook 写 `ready.json`，unattended-hook 写 Pending Decision | JSON 文件，原子写 |
| Hook 入口 | Host CLI | 返回结果让 Host 继续、拒绝提问或拦下调用 | 退出码 0/2，stdout JSON，stderr 原因 |
| Hook 入口 | sideby 配置 | network-hook 和 unattended-hook 每次调用都重读开关 | `config.json` |
| Network Guard | 外部网络端点 | 开启时经 Account 的代理变量发一次请求，只留国家和地址的 SHA-256 | HTTPS GET `/cdn-cgi/trace` |
| Update | 外部网络端点 | 每天至多一次查询最新版本，不带任何 Account 信息 | HTTPS GET `/-/package/sideby/dist-tags` |
| Claude Code mod | sideby CLI | 定时读取会话列表来显示标签和面板 | `sideby sessions --json` |
| Agent Skill | sideby CLI | 指导用户的 AI 运行命令 | `sideby … --json` |
