## Components

| Name | Type | Responsibility | Code path |
| --- | --- | --- | --- |
| sideby CLI | Entry (Node executable) | Parses arguments and dispatches each subcommand to its command function; input and output only | `src/cli/main.ts`, `src/cli/commands.ts`, `src/cli/args.ts` |
| Panel | Entry (local HTTP server + inline web page) | Shows and acts on each Account's health, Quota, Usage and Sessions at `127.0.0.1:17420` | `src/panel/server.ts`, `src/panel/handler.ts`, `src/panel/background.ts`, `src/panel/page.ts` |
| Menu Bar Item | Entry (macOS JXA script, started by a LaunchAgent) | Draws the Quota snapshot in the menu bar and turns clicks into sideby commands; reads no files and decides nothing itself | `src/menubar/script.ts`, `src/menubar/agent.ts`, `src/menubar/snapshot.ts` |
| Runtime | In-process service layer | `createRuntime()` reads config, loads Plugins and gives the CLI and the Panel the same set of methods | `src/runtime.ts` |
| Library entry | Public contract | Exports `createPanelHandler`, `startPanelServer`, `createRuntime` and the Plugin types for Portals and tools built on sideby | `src/index.ts`, `src/types.ts` |
| Accounts and Doctor | Core module | Discovers Accounts on disk, checks Shared Items by Share Mode, reports Findings, applies safe Fixes and creates Accounts | `src/core/accounts.ts`, `src/core/share-modes.ts`, `src/core/doctor.ts`, `src/core/create.ts`, `src/core/fs-safe.ts` |
| Plugin loader | Core module | Loads built-in and user Plugins, runs the owner and permission trust checks, and runs Hooks through the HookBus | `src/plugins/loader.ts`, `src/plugins/bus.ts`, `src/plugins/account-script.ts` |
| Family Plugins | Adapter layer (one per Host) | Describe a Host's directory convention, Shared Items and launch arguments, plus its Quota, Usage, Session and Handoff readers | `src/families/index.ts`, `src/families/claude/`, `src/families/codex/`, `src/families/grok/`, `src/families/pi/`, `src/families/agy/`, `src/families/shared/` |
| Quota and Usage | Core module | Decides when to ask a Host for its Quota, keeps the answers, computes warning levels and the Handoff pick | `src/core/quota-fetch.ts`, `src/core/quota-store.ts`, `src/core/quota-levels.ts`, `src/core/handoff.ts`, `src/core/limit-reset.ts` |
| Session services | Core module | Lists Live Sessions, maintains the History Index, and stores and delivers Messages between Sessions | `src/core/live-sessions.ts`, `src/core/history-index.ts`, `src/core/history.ts`, `src/core/messages.ts` |
| Launch | Core module | Builds the environment and arguments that belong to one Account only and spawns the Host; under Auto Handoff it stays the Host's parent process | `src/core/launch.ts`, `src/core/secret-file.ts`, `src/core/session-hooks.ts`, `src/core/handoff-run.ts`, `src/core/handoff-chain.ts` |
| Hook entries | Entry (run by the Host, builds no Runtime) | The four commands `statusline-tap`, `handoff-hook`, `unattended-hook` and `network-hook`; they import only leaf modules and read or write state files, or block the Host, during a session | `src/quota/statusline-tap.ts`, `src/handoff/hook.ts`, `src/unattended/hook.ts`, `src/network/hook.ts` |
| Network Guard | Core module | Looks up the Egress country through the Host's proxy settings and refuses the Launch when it is not on the allow list | `src/core/egress.ts`, `src/core/network.ts` |
| Update | Core module | Asks the npm registry for the latest version at most once a day, gives the Update Notice and updates by Install Method | `src/core/update.ts` |
| Desktop integration | Core module | Installs the Dock icon or `.desktop` entry, starts the Panel at login, and opens a Desktop App per Account | `src/desktop/app.ts`, `src/core/autostart.ts`, `src/core/desktop-app.ts` |
| sideby config | Local files | Holds `config.json` (aliases, handoff, unattended, network and more) and the user Plugin directory, in `~/.config/sideby/` | `src/core/paths.ts`, `src/core/config.ts` |
| sideby state directory | Local files | Holds kept Quota answers and the Claude quota cache, the History Index (SQLite), Messages, Handoff files, Pending Decisions and the Panel pid file, in `~/.local/state/sideby/` | `src/core/paths.ts`, `src/core/quota-store.ts`, `src/families/claude/quota-cache.ts`, `src/core/history-index.ts`, `src/core/unattended-pending.ts` |
| Account directories | Local files (owned by the Host) | One Host config directory per Account (such as `~/.claude`, `~/.claude-<name>`), holding the login, session records and Shared Items | `src/families/claude/layout.ts`, `src/families/index.ts` |
| Host CLI | External program | Claude Code, Codex, Grok Build, pi, Antigravity CLI; sideby launches it but never modifies it | `src/families/claude/index.ts`, `src/families/codex/index.ts` |
| External network endpoints | External service | The npm registry's `latest` dist-tag, and each vendor's own `/cdn-cgi/trace` | `src/core/update.ts`, `src/core/network.ts` |
| Portal | External program | Another local server that mounts `createPanelHandler` under its own path and shows the Panel in an iframe | `src/index.ts`, `src/panel/handler.ts` |
| Agent Skill | Docs shipped in the package | Lets the user's AI install, configure and troubleshoot through `sideby … --json` | `skills/sideby/SKILL.md`, `skills/sideby/references/` |
| Claude Code mod | Host extension shipped in the package | Loaded by `sideby run` with `--plugin-dir`; shows the Session Label, Message toasts and the `/sessions` pane | `mods/claude/hooks/register.js`, `src/families/claude/mod.ts` |
| JSON Schemas | Generated (public contract) | Describe the structure of the config and of every `--json` output | `schemas/`, `src/cli/json-schemas.ts`, `src/cli/schemas.ts` |
| Test tools | Library shipped in the package | Provide a fake HOME, fake Host executables and directory snapshots; also exported as `sideby/testing` | `testing/index.ts`, `testing/demo.ts` |

## Relationships

| From | To | Action | Protocol or data |
| --- | --- | --- | --- |
| User or AI agent | sideby CLI | Types a command in a terminal | `sideby <command> [--json]`, exit codes 0/1/2/10 |
| User or AI agent | Panel | Opens it in a browser and clicks actions | HTTP, `http://127.0.0.1:17420/`, with a token |
| User or AI agent | Menu Bar Item | Clicks the icon or presses `⌥X` | macOS menu events |
| Menu Bar Item | sideby CLI | Starts a child process every 120 seconds for a snapshot, and turns clicks into commands | `sideby menubar snapshot --json` (NSTask) |
| sideby CLI | Panel | Starts the server in the foreground or detached in the background | `sideby ui`, `sideby ui --background` (internally `--serve-detached`) |
| sideby CLI | Runtime | Creates and calls it inside command functions | in-process `createRuntime()` |
| Panel | Runtime | Gets and calls it for each request through `runtimeFactory` | in-process method calls |
| Portal | Panel | Mounts the handler and passes the theme and options | `createPanelHandler(options)`, same-origin iframe |
| Runtime | sideby config | Reads the config; writes settings such as aliases back atomically | `config.json` (JSON) |
| Runtime | Plugin loader | Loads every Plugin at startup | `loadPlugins({ builtins, config, bus, userPluginsDir })` |
| Plugin loader | sideby config | Reads each user Plugin's manifest and dynamically imports its entry | `plugins/<name>/plugin.json`, `import()` |
| Plugin loader | Family Plugins | Calls `register(api)` and takes each FamilyDef | `api.family(def)` |
| Runtime | Accounts and Doctor | Discovers Accounts, runs checks, applies Fixes, creates Accounts | `discoverAccounts`, `runDoctor`, `applyFixes`, `createAccount` |
| Accounts and Doctor | Account directories | Reads item states, creates symlinks or copies, writes Fixes atomically | file system; credential files are checked for type and mode 600 only |
| Runtime | Quota and Usage | Reads each Account's Quota and Usage, and ranks Accounts for `sideby next` | in-process method calls |
| Quota and Usage | Family Plugins | Calls the Family's readers at intervals | `FamilyDef.fetchQuota`, quota and usage reader functions |
| Quota and Usage | sideby state directory | Keeps each Account's latest answer and limits concurrency with a lock | `quota/<family>/<name>.fetched.json` |
| Family Plugins | Account directories | Reads only session records and the identity fields of login files | Claude `projects/**/*.jsonl`, Codex `sessions/**/rollout-*.jsonl` |
| Family Plugins | Host CLI | Starts the Host's own command to ask for its Quota, without starting a model turn | `claude -p /usage --output-format json`, `codex app-server` `account/rateLimits/read` |
| Family Plugins | sideby state directory | Reads the Claude quota cache the tap wrote | Claude Quota cache (JSON) |
| sideby CLI | Session services | Lists Live Sessions, searches Session History, sends Messages, passing the Runtime as an argument | in-process function calls (`sessions`, `history`, `send`, `messages` commands) |
| Panel | Session services | Lists Live Sessions and Messages and sends Messages from the page, passing the Runtime as an argument | in-process function calls (`sendMessage`, `listMessages`) |
| Session services | Runtime | Gets the Account list, the Family table and the read context | `rt.accounts()`, `rt.families`, `rt.readContext()` |
| sideby CLI | Launch | Runs the Host from a prepared launch, or hands it to the relay loop under Auto Handoff | `runHost(prepared)`, `runWithHandoff(rt, ref, args)` |
| Session services | Family Plugins | Calls each Host's session readers and deliverers | `liveSessionReader`, `historyReader`, `DELIVERERS` |
| Session services | sideby state directory | Rebuilds and queries the History Index, and stores a Message before delivering it | SQLite (`node:sqlite`, FTS5), Message files |
| Runtime | Launch | Prepares the launch of one Account | `prepareLaunch(ref, args, command)` |
| Launch | Plugin loader | Runs the `launch.before` Hook before launch; a Hook may change the environment or stop the launch | `bus.run('launch.before', …)` |
| Launch | Account directories | Reads the Secret File and puts it only into the child process environment | `proxy.env` |
| Launch | sideby state directory | Writes this session's hook settings file; watches Handoff's `ready.json` | Claude `--settings` file, `ready.json` |
| Launch | Host CLI | Spawns the child process, which inherits the terminal | environment variables `CLAUDE_CONFIG_DIR` / `CODEX_HOME` / `GROK_HOME`, `SIDEBY_ACCOUNT`, Host arguments |
| Launch | Host CLI | Under Auto Handoff, ends the old Host and then starts the next Account | `SIGTERM` (waits 10 seconds, never kills), the Handoff Brief's path |
| Host CLI | Account directories | Reads and writes its own login, settings and session records | the Host's own formats |
| Host CLI | Hook entries | Runs commands on events such as a status line refresh, a tool call or the end of a turn | `sideby statusline-tap`, `sideby handoff-hook`, `sideby unattended-hook`, `sideby network-hook`, stdin JSON |
| Hook entries | sideby state directory | The tap writes the Claude quota cache, handoff-hook writes `ready.json`, unattended-hook writes Pending Decisions | JSON files, atomic writes |
| Hook entries | Host CLI | Return a result that lets the Host continue, declines a question or blocks a call | exit codes 0/2, stdout JSON, reason on stderr |
| Hook entries | sideby config | network-hook and unattended-hook read the switches again on every call | `config.json` |
| Network Guard | External network endpoints | When on, sends one request through the Account's proxy variables and keeps only the country and a SHA-256 of the address | HTTPS GET `/cdn-cgi/trace` |
| Update | External network endpoints | Asks for the latest version at most once a day, carrying no Account information | HTTPS GET `/-/package/sideby/dist-tags` |
| Claude Code mod | sideby CLI | Reads the session list on a timer to show the label and the pane | `sideby sessions --json` |
| Agent Skill | sideby CLI | Guides the user's AI to run commands | `sideby … --json` |
