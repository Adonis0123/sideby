# 面板

[English](panel.md) | 中文

← [README](../../README.zh-CN.md)

```sh
sideby ui              # http://127.0.0.1:17420，自动打开浏览器
sideby ui --port 8080
sideby ui --no-open    # 只打印地址
```

面板只监听 `127.0.0.1`。端口上已经有一个 sideby 面板时，直接打开那个面板；端口被别的程序占用时，依次试后面的端口，并打印最终地址。页面显示每个账号的登录邮箱、按列对齐的各额度窗口和最近使用；点一下账号，可以看它的运行方式、token 用量和健康状态。本地记录有会话、但没有 token 数时，这一格显示会话个数，并写明记录里没有 token 数；最近使用取这些会话里最新的一条。名字后面是短命令，再最多一个标签，按要紧程度取一个：「需要修复」「快用完」、其他要看一眼的情况（没登录、工具缺失、「看一下」），然后是「建议使用」；悬停能看到原因。账号的网站在 Chrome 里登录过时，展开后会写出是哪个浏览器用户，点一下用它打开。页面打开时每 20 秒自动刷新，开启额度后的几分钟里每 5 秒刷新一次，status line 一上报就能看到第一批数字。「显示」里的「隐藏邮箱」会把地址显示成 `a•••@example.com`，方便共享屏幕。同一工具里登录同一个身份的账号（Claude Code、Codex、Grok Build）在列表里排在一起：上面一行的名字后有一个链接图标（悬停看哪些目录共用这个登录），再写 email 和这份额度，只显示一次（鼠标悬停可以看到读自哪个账号，提醒的圆点也在这一行）；下面每个目录一行，写它自己的名字、模型、最近使用和菜单，点组头可以把它们收起（见[两个目录，同一个登录](usage.zh-CN.md#两个目录同一个登录)）。搜索后只剩其中一个，或者用卡片视图时，每个账号自己显示额度，并写「与 … 同一登录」。「显示」里还能切换已用或剩余额度、列表或卡片。哪些账号展开着，面板会在你的浏览器里记住。展开后，Claude Code 和 Codex 账号会显示它用的模型和 effort；点它，或账号菜单里的「模型和 effort…」，就能只为这个账号设置（见[模型与 effort](usage.zh-CN.md#模型与-effort)）。在 macOS 上，装了桌面应用的 Claude Code、Codex 订阅账号行尾、终端按钮左边有一个显示器按钮，菜单里也有「打开桌面应用」（同一登录的分组直接打开：已在运行的切到前台，否则用这一行显示的目录），用这个账号打开 Claude Desktop 或 Codex 应用（见[桌面应用](usage.zh-CN.md#桌面应用)）。装了 Grok Bot 时，账号下面有一组 **Grok Bot**，列出它的各个窗口（各自登录），也能再开一个（见 [Grok Bot 窗口](usage.zh-CN.md#grok-bot-窗口)）。每个账号的菜单里有「上下文调优」，内容和 `sideby tune` 一致；「使用」按钮先展示改动，确认后写入推荐值，「撤销」可以改回原值（见[上下文调优](usage.zh-CN.md#上下文调优)）。页面上还有带一键修复的体检、新建账号（可顺手加短命令），还能在展示 diff 后开启 Claude 额度。一次开启对所有 Claude Code 账号生效，所以「开启额度显示」按钮只在 Claude Code 分组标题里，不在每个账号上。没登录的账号旁有「登录」：它打开你的终端，在里面运行 `sideby login <account>`（不经过 AI）。登录始终在你自己的终端里完成；终端打不开时，面板把命令复制好，让你自己粘贴。账号详情里显示的浏览器用户不对时，点旁边的「更改」选对的那个（见[在哪个浏览器登录过](usage.zh-CN.md#在哪个浏览器登录过)）。已登录账号的菜单里有「重新登录或换账号」，同一登录的每个目录有「换个账号登录」，两者运行同一条命令。

**置顶和账号菜单。** 置顶的账号名字前有一个小图钉，点它取消置顶。鼠标移到其他账号上（或用键盘移到它那一行），同一位置会出现一个更浅的图钉，点它把这个账号置顶到所在分组的最前（每个工具最多 3 个）。在账号行或卡片上按右键，会在点的位置打开和「…」按钮一样的菜单；用键盘时，在聚焦的行上按菜单键或 Shift+F10 也能打开。在输入框、链接和按钮上右键，仍然是浏览器自己的菜单。

**搜索**（顶栏的按钮，或 Cmd/Ctrl+K）按名字找到一个页面、一项设置或一个操作，中英文都行，并带你过去：设置会打开它所在的位置并短暂高亮，操作会打开它原有的预览，确认之前什么都不改。框里没字时列出最近用过的和几个常用项。它只找功能，不找会话：最后一行用同样的词搜索会话历史。`/` 和 Cmd/Ctrl+F 仍然跳到账号搜索。在终端里，`sideby commands <词>` 搜索同一份列表。

**设置**把只需设一次的东西分成几组：外观（明暗、主题、语言）、启动、账号与额度、让 AI 帮我。明暗和语言存在 sideby 的配置里，所以 `sideby config set panel.theme dark` 也能改。「启动」里的「登录后在后台启动 sideby」（macOS、Linux 桌面，以及 WSL，在 WSL 里叫「登录 Windows 后在后台启动 sideby」）会在每次登录时启动面板，不打开窗口，打开面板时就是最新状态。打开或关闭时，先显示要写入或删除的文件和要运行的命令，你确认后才生效。终端里用 `sideby autostart on|off` 也一样。macOS 上的「在状态栏显示额度」会在状态栏放一个 sideby 小人图标，同样先预览再生效；面板第一次显示额度时会提示一次。终端里用 `sideby menubar on|off`。开着时，没在运行会直接写出来并给「重新启动」；下面的「状态栏图标 ›」点进去是它自己的对话框：上面是打开菜单的快捷键（从下拉里选 ⌥X、⌥Z、⌥⌘S、⌃⌥S 或关闭，想自己按就选「自定义…」；终端里用 `sideby menubar hotkey`），下面是「看不到图标？」，列出三种原因（状态栏放不下被 macOS 收进顶栏的 «、在「系统设置 › 菜单栏」里被关掉、被 Ice 或 Bartender 这类整理工具收起来）。图标被收进 « 时，开关下方会直接提示，并给「让 AI 帮我排查」，开一个 AI 任务替你找原因。

## 主题

**设置 › 主题**选面板的颜色。内置五套，底色都是同一种冷灰，只有强调色不同：**青绿**（默认）、**叶绿**、**阿根廷蓝**、**Claude 橙**和 **Codex 墨黑**（像 Codex 应用一样黑白）。原来的晴空现在叫阿根廷蓝。它们排成一行色点：点一个色点，或用方向键在这一行里移动，就换过去。正在用的色点外面有一圈同色细环，鼠标移上去会显示名字。颜色平滑过渡、不刷新页面，底部提示里可以**撤销**。色点下面，**自选主色**把按钮、链接和额度条换成你挑的颜色；**让 AI 帮我配色**把一句话（比如“像 Notion 一样素净”）交给你自己的 AI：它写一套主题，先在面板里给你看，你同意后才换上。

琥珀色和红色只在额度快用完、用完时出现，所以一眼就能看到。文字对比度按 WCAG（4.5:1，主按钮上的白字 3:1）；你自己的主题里有颜色太淡看不清时，面板会自动调深或调浅，并写明。sideby 小人的蓝色不随主题变。

自己的主题是 `~/.config/sideby/themes/` 里的一个 JSON 文件，只放颜色，不放代码：

```json
{ "schemaVersion": 1, "name": "Calm green", "base": "leaf", "accent": "#4f9d69", "light": {}, "dark": {} }
```

多数时候给 `base` 和 `accent` 就够了；`light`、`dark` 用的 token 和下面嵌入页面的 `theme` 一样。终端里：`sideby theme` 列出全部，`sideby theme use <名字>` 切换（`--undo` 换回），`sideby theme check <文件>` 报告对比度，`sideby theme preview <文件>` 在运行中的面板里看一眼、不切换，`sideby theme import <文件>` 保存。

## 会话

「会话」页列出每个账号现在在跑的会话，一个会话一行：工具图标、会话标签（账号短名、工具给这个会话起的标题、id 前 8 位）、状态（需要你处理、运行中或空闲）、工作目录和最近活动时间。需要你处理的排在最前。sideby 没法确定一个账号在跑哪个会话时，显示它最新的一个，并标「最新会话（推测）」。这一页打开时每 5 秒刷新一次，点右上角的「刷新」会立刻重读。

「复制给 AI」复制一段说明，另一个 AI 照着就能接上：是哪个账号、会话在哪个目录、记录在哪（只写路径，不包含对话内容）。按钮会短暂变成对勾。旁边的「…」菜单可以复制会话 id，或在原账号里恢复这个会话的命令（Claude Code 的会话是 `sideby resume claude -- --resume <id>`）。会话跑在 Orca 的终端里时，这个菜单还有「跳到它的 Orca 标签页」，把那个标签页切到前面。浏览器不让复制时，文字会显示出来并已选中，按 ⌘C 或 Ctrl+C 即可。终端里 `sideby sessions` 列出同样的会话；也可以跟你的 AI 说，比如「把 cc002 当前的会话复制给另一个 AI」。

用本机的编排工具（如 `agent-dispatch` skill）把一件事分给几个会话时，属于某个任务（Run）的会话会多一个标签「任务：<标题>」。点它在浏览器里打开这个任务的看板；悬停可以看到这个会话负责哪一部分，带「+N」时还能看到它同时在做的其他任务。只有编排工具列出了这个会话、并且看板文件在编排工具自己的目录里时才显示。只读面板不显示它。也可以问你的 AI「cc002 在哪个任务里」。

### 发给会话

点一行的「发给它」，会打开一个以该会话标签为标题的小窗。写下要它做的事，需要时加截图：按 ⌘V 或 Ctrl+V 粘贴、拖进小窗，或点「添加截图」选文件（只收图片，最多 5 张，每张不超过 20 MB）。按 ⌘Enter 或 Ctrl+Enter 发送。sideby 先把消息存成文件，不会丢，再交给这个会话：

- 「已送达」：会话已经收到。它读了以后，这一行显示「已读」。
- 「需要你粘贴」：这个工具自己收不了消息。小窗里给出一句话和「复制这句」按钮，粘贴到那个会话的标签页即可；会话跑在 Orca 里时，还有「跳到它的 Orca 标签页」。
- 「等批准」：Claude Code 会话收到了，但要你在它的终端里批准后才显示，约 5 分钟没人批准就丢掉（跳过权限检查启动的会话，账号没另设时就会这样）。小窗和这一行都有「直接接收」。没人及时批准时，这一行会变成「需要你粘贴」。

会话页底部的「接收消息」（有账号扣着消息时，页顶还有一条黄色横幅）列出每个 Claude 设置文件、用它的账号，以及是直接接收还是等批准。点「直接接收」，会把没设或设为 hold 的文件里的 `crossSessionInbound` 改成 `"accept"`，别的都不动；之后的提示里有「撤销」。设成 `"refuse"` 的文件不会动。正在运行的会话重启后生效。终端里用 `sideby messages inbound accept` 做同样的事。

每一行会显示你最近发给它的消息到了哪一步：「已送达」「等批准」「已读」或「需要你粘贴」。不管你在哪一页，有会话收到消息（包括别的 AI 用 `sideby send` 发的）、读了消息，或有消息等你粘贴时，角落会弹一条提示；点「查看」跳到那个会话的那一行。有消息等你粘贴时，提示上有「复制这句」，「会话」页签上显示等着的个数；点行上的「需要你粘贴」能看到要粘贴的那句话和原因。只读面板不显示「发给它」。终端里用 `sideby send <账号> "<内容>" --image <路径>` 做同样的事；也可以跟你的 AI 说，比如「告诉 cc002 再跑一遍测试，把结果发给我」。

### 历史

**会话**页顶部的分段是 **历史 / 运行中**，打开会话页默认就是 **历史**：你以前的所有会话，覆盖每个工具的每个账号（Session History）；**运行中** 是正在跑的会话。第一次打开时 sideby 才去读；第一次还会建本机的搜索索引，页面会显示建到哪了。

- 左栏 **项目**：会话所在的每个 git 仓库，worktree 和子目录都算进去，带会话数。**所有项目** 在最上面。
- 列表上方的 **搜索框**：输入你记得的内容，中英文都行。每个词都要在标题、项目、分支、账号、你的提问或回答里命中；用引号括起来（"fix login"）就按整句找。旁边是工具、账号和时间筛选（**今天**、**7 天**、**30 天**、**全部**）。勾上 **也搜命令和输出**，会把当前范围内的会话文件也读一遍，找命令输出和报错；会慢一些，sideby 什么都不存。选了项目却搜不到时，点 **搜所有项目** 就在全部项目里找。刷新页面后，搜索词、筛选和选中的项目都还在；新开的标签页从头开始。
- 每行显示 Session Title（你起的名字，没有就用工具的标题，再没有就用你的第一条提问）、命中的片段或第一条提问、工具、账号、分支、消息数和多久以前；正在运行的会话带标记。子代理会话折在启动它的会话里。脚本、SDK 或别的 agent 启动的会话默认隐藏，勾上 **显示程序启动的会话** 才显示。滚到底会继续加载。
- 列表上方的 **显示** 给会话分组：按 **项目**（默认）、**日期**、**账号**、**AI**，或不分组；你的插件把项目分了类时还有 **分类**（见 [插件](plugins.zh-CN.md)），这时左栏的项目也按分类分层，点分类标题可以把它收起或展开，拖动分类标题（或按 Alt+方向键）可以调整分类顺序，只在这个浏览器里生效。点组头可以折叠这一组；分组方式和折叠的组记在这个浏览器里。同一个菜单里的 **展开 N 个已折叠的组** 一次全部展开。
- 列表下方是 **这些会话从哪来**：每个账号读到多少会话；某个账号没有会话或读不了时写明原因。插件加的工具，只有插件提供了会话读取器才有历史；否则选中它时页面会直接说明。索引还在建时，列表上方那行会写明进度。

每行上直接有 **查看对话** 和 **继续**；右键一行（或按 Shift+F10）打开和 **···** 一样的菜单。点一行，会在对话框里只读显示这个会话：先显示最新的 200 条消息，顶部的 **显示更早的消息** 加载更早的，工具调用每个折成一行，回答里的 Markdown（表格、代码、列表）按格式显示。**继续**（菜单里叫 **复制继续命令**）复制 `cd <它的目录> && <在原账号恢复它的命令>`，粘到终端里就能接着做。文件夹已经不在时，按钮会提示工具可能找不到这个会话，这时用 **复制给 AI** 总能接上。**复制给 AI** 复制它的 Session Reference，和运行中的会话一样。

搜索索引存标题、项目、你的提问和回答，不存工具输出，放在只有你能读的 sideby 状态目录里。config `history.index: false` 会关掉并删除它，之后只搜标题和目录。终端里用 `sideby history` 做同样的事，也可以让 AI 帮你，比如「找到我上周改登录页的那个会话」。

## 无人值守

「无人值守」页用来在你离开时让会话继续跑（见[无人值守](usage.zh-CN.md#无人值守unattended-mode)）。顶部的卡片用一句话写开没开、为什么、到几点，比如「已开启 · 时段『工作日夜间』· 到 08:00」「已暂停 · 到 08:00 后恢复」「未开启 · 下一次 周一 23:00」。「现在开」会弹出一个小选择：到当前或下一个时段结束（有时段时才有）、4 小时、12 小时，或到你选的时间（早于现在就是明天，显示「到明天 07:30」）。开着时同一个按钮变成「现在关」，在时段内是「暂停到这一段结束」；顶栏显示「无人值守 · 到 08:00」，点它回到这一页。

下面的时间表每个时段一行：一到日的星期按钮、开始和结束时间（结束过了午夜时后面写「次日」）和删除按钮。「添加时段」和「工作日夜间 23:00–08:00」一点就加。没有保存按钮：每次改动立即写进 sideby 的 config，之后的提示里有「撤销」。「待你决定」按会话分组列出会话留给你的事：时间、账号、类型（提问、要你确认的操作、没做的操作）和原文，按钮是「已处理」和「回到会话」（会话还在跑时在会话页找到它，已结束时复制恢复命令）。最后几行写受保护范围：sideby 启动的 Claude Code 和 Codex 会话；Codex 要先在 `/hooks` 里信任 hook，而且只管提问；Grok Build 和 pi 暂不支持。只读面板能看到全部内容，但不能修改。命令行里用 `sideby unattended`，或者跟你的 AI 说「今晚无人值守，到明早 8 点」。

## 谁能访问面板

面板只监听 `127.0.0.1`，所以别的电脑连不上。其他网站的网页也读不到它，也不能借它做操作：面板会检查每个请求从哪里来，任何改动都要带一个只有面板自己的页面才拿得到的钥匙。它做不到的是区分同一台电脑上的不同用户。同一台 Mac 上另一个用户运行的程序，能读到面板显示的内容（账号名、邮箱、额度和用量，从不包括凭据），也能按它的按钮。电脑只有你一个人用时，这不影响什么。和别人共用一台 Mac 时，需要时再用 `sideby ui` 打开面板，不要开「登录后在后台启动」，也不要用 `sideby ui --background`。

## 让 AI 帮我

不想自己琢磨的事，面板可以交给你自己的 AI。它会打开你的终端，用你自己的一个账号（Claude Code、Codex 或 Grok Build）启动，并附上一段说明要做什么的短提示。之后 AI 按 sideby skill 干活，你在那个终端里看着，回答它的问题。

| 入口 | 交给 AI 的事 |
|---|---|
| 顶栏的「让 AI 帮我」，以及「设置」里的同名入口 | 你写什么都行 |
| 体检里不能一键修复的发现旁边 | 修好这些发现 |
| 没有数据或出错的额度格 | 找出原因，让额度显示出来 |
| 新建账号对话框底部的「让 AI 帮我配」 | 加一个账号：订阅账号，或者你手上有 API 地址、文档链接的账号 |
| 新建账号对话框工具列表最后一项「其他工具……」 | 让 sideby 支持一个还没列出的工具，先在你电脑上做成插件 |
| 「设置」里的「让 AI 写插件」 | 写一个插件或 hook |
| 「首选终端」里自定义命令旁的「不会写？让 AI 帮我配」 | 为你用的终端写好并保存一条自定义终端命令 |
| 「自动接力」页上的「让 AI 帮我调」 | 按你的账号推荐接力的阈值和顺序，你同意后再改 |

每个入口的对话框有自己的标题和几条这件事的示例，点一下就填进输入框。入口本身已经说明了问题时（体检发现、额度格），输入框可以不填。

打开之前，确认框会写明用哪个终端、哪个账号，例如「在 Orca 中打开，并在那里启动 claude:work」，两者都能改。sideby 默认挑已登录、剩余额度最多的订阅账号，你改过的选择下次接着用。API 账号不会被自动挑中，但你可以手选。没有能用的账号时，确认框改成「复制提示词」，你可以贴给任何 AI。

AI 要守的规则：改东西之前先给你看改动，等你同意；从不替你登录；从不向你要 API 密钥。密钥通过面板的「填写密钥」或终端里的 `sideby key <account>` 输入，不会显示出来，也不会发给 AI。你在输入框里贴了像密钥的内容，面板会把它删掉并提示你。做完之后，AI 会问你愿不愿意把这次的改进分享给 sideby；只有你同意，它才会在去掉你自己的账号名、路径和邮箱之后提 PR。

**截图和视频。** 把截图粘贴进对话框、把文件拖进去，或者点「添加图片或视频」。图片（PNG、JPEG、GIF、WebP）单个最大 20MB，视频（MP4、MOV、WebM）单个最大 200MB，一次最多 5 个；sideby 按文件内容判断类型，不看文件名。每个文件显示成一张小图，可以单独删掉。AI 会拿到这些文件的路径和你写的话（Codex 还会直接收到图片），所以先确认里面没有密钥或密码。文件存在 sideby 自己的目录里，7 天后删除。只读面板不能添加文件。

**打开哪个终端。** 在「设置」的「首选终端」里选，列表只显示这台电脑装了的终端。没选时，sideby 用启动面板的那个终端，再不行就用「终端」（Terminal）。macOS 上支持 Terminal、iTerm2、Ghostty、Orca、WezTerm、kitty 和 Alacritty；Warp、VS Code 和 Cursor 暂时不能这样运行命令。在 WSL 上，sideby 在 Windows Terminal 里开一个新标签页，回到同一个 Linux 发行版和文件夹运行（这也是 WSL 上的默认终端）；任务文件夹或命令里有 `;` 或 `"` 时，改为复制命令。装在 Windows 上的 Orca 也能从 WSL 打开：终端以 WSL shell 打开，位置是你在 Orca 里最近用过的那个 WSL 项目。Orca 会在它当前激活的 worktree 里开新终端。从面板应用或 `sideby ui --background` 启动的面板可能不知道你用哪个终端，请在「设置」里选一个。`sideby terminal` 显示同样的列表，`sideby terminal --set <id>` 保存你的选择。「设置」里的「自定义终端命令」可以填一个模板来支持其他终端，`{cmd}` 和 `{cwd}` 由 sideby 填入。

**终端打不开时。** 面板会复制一条命令 `sideby ask --run <id>`，提示你粘贴到任意终端回车，效果一样。sideby 第一次打开 Terminal、iTerm2 或 Ghostty 时，macOS 会问是否允许 sideby 控制它；如果你点了不允许，去「系统设置 → 隐私与安全性 → 自动化」里打开。任务保留一小时，过期后再点一次即可。

终端从 sideby 自己的一个目录开始，AI 不会顺手读你的某个项目。

**AI 的权限检查保持开启。** AI Task 像 `sideby run` 一样启动账号，只是去掉账号设置里跳过宿主权限检查的参数。Claude Code 用它的 auto 模式启动：日常操作不打断你，但运行下载来的代码、force push、删掉你原有的文件这类有风险的操作会先经过检查。Codex 去掉 `--dangerously-bypass-approvals-and-sandbox`（`--yolo`），按你自己的 Codex 设置来。其他工具照旧启动。你自己用 `sideby run` 开的会话，参数一个不少。这些不用面板也能做：`sideby ask "帮我加一个 DeepSeek API 账号"`（见[命令](commands.zh-CN.md)）。

## 面板应用

```sh
sideby app install       # macOS：~/Applications/sideby.app；Linux：应用菜单里的「sideby」
sideby app uninstall
sideby ui --background   # 应用实际执行的命令：不占终端启动面板，然后打开它
sideby ui --stop         # 停掉后台面板
```

双击应用就能打开面板。没有面板在运行时，它在后台启动一个（`sideby ui --background`）；已经有了就直接复用，然后打开浏览器。关掉标签页后，后台面板继续运行，日志写到 `${XDG_STATE_HOME:-~/.local/state}/sideby/panel.log`。从 Finder 或桌面菜单启动的程序只拿到很短的 PATH，所以后台面板会向你的登录 shell（`$SHELL -ilc`）要 PATH，好找到 `~/.local/bin` 这类目录里的宿主。

应用运行的是安装时那份 Node 和 sideby。`sideby update`（以及面板的「更新」按钮和自动更新）会用新版本重新安装应用，图标也一起换新。升级了 Node，或用别的方式装了 sideby，就自己再跑一次 `sideby app install`。如果你自己的页面嵌入了面板（见下文），`sideby app install --url http://localhost:3000/` 让应用改为打开这个地址；再次安装会沿用这个地址。要让应用改回启动面板，先跑 `sideby app uninstall`，再跑 `sideby app install`。安装和卸载只动 `sideby app install` 自己创建的文件。这个应用是本机未签名的启动脚本，不适合拷到别的机器上用。

## 嵌入面板

别的本地 Node 网页可以把面板挂在自己的路径下。handler 照常做 Host、Origin 和 token 校验，你只需列出自己网页使用的主机名。

```ts
import { createServer } from 'node:http'
import { createPanelHandler, createRuntime } from 'sideby'

const panel = createPanelHandler({
  runtime: () => createRuntime(), // 传工厂函数：每个请求都读到磁盘的最新状态
  basePath: '/accounts',
  allowedHosts: ['tools.localhost:8080'],
  theme: {
    colorScheme: 'light', // 默认 'auto'，跟随系统
    header: 'bar', // 通栏页头，而不是放在页面底色上的标题
    light: { font: '-apple-system, "PingFang SC", sans-serif', bg: '#f2f8fc', primary: '#e1f0fb', onPrimary: '#1f6396', radius: '10px', shadow: 'none' },
  },
  lang: 'en', // 默认 'auto'：先用面板里选过的语言，再看浏览器语言
})
createServer(async (req, res) => {
  if (!(await panel(req, res))) res.writeHead(404).end()
}).listen(8080, '127.0.0.1')
```

`theme` 让面板和你的页面风格一致。token 会写成面板自带的、带 nonce 的 `<style>` 里的 CSS 自定义属性，面板严格的 CSP 不需要放宽。iframe 读不到父页面的 CSS 变量，所以要传具体值。

- **token**（都可选）：字体排版 `font`、`monoFont`、`fontSize`、`smallSize`、`controlSize`、`headingSize`、`largeSize`、`titleSize`、`titleWeight`、`headingWeight`、`strongWeight`、`buttonWeight`、`primaryWeight`；颜色 `bg`、`surface`、`surfaceMuted`、`border`、`borderStrong`、`text`、`muted`、`faint`、`hover`、`active`、`accent`、`accentSoft`、`focus`、`primary`、`primaryHover`、`primaryActive`、`onPrimary`、`primaryBorder`、`primaryHoverBorder`、`buttonText`、`buttonHoverBorder`、`buttonHoverText`、`checkColor`、`ok`、`okSoft`、`warn`、`warnSoft`、`fail`、`failSoft`、`okBar`、`warnBar`、`failBar`、`track`、`logoBg`、`logoColor`、`logoBorder`、`shadow`、`focusOutline`、`focusRing`；形状与布局 `radius`、`controlRadius`、`chipRadius`、`primaryRadius`、`controlHeight`、`controlHeightSmall`、`fieldHeight`、`contentWidth`、`gutter`。每个 token 的含义见 [`src/panel/theme.ts`](../../src/panel/theme.ts)。
- **浅色与深色**：`light` 里的颜色只在浅色模式生效；字体排版、形状和布局 token 两种模式都生效。深色模式的颜色写在 `dark` 里；你的页面没有深色模式时，设 `colorScheme: 'light'`。
- **创建 handler 时校验**：未知 token，或值里出现字母、数字、空格和 `# % ( ) , . + - / ' " _` 以外的字符（也就是不允许 `;`、`{`、`}`、`<`、`\`、`*`、`:`），或含 `url(`、括号或引号不成对、超过 200 个字符，都会抛出写明 token 名的 `TypeError`。
- 不传 `theme` 时，外观和 `sideby ui` 一样。你给的颜色是面板在你页面里的默认颜色，在面板的**设置 › 主题**里显示为“这个页面的配色”；用户选了别的主题，颜色就以用户选的为准，字体、尺寸等其他 token 仍按你的。

`updates`（默认 `true`）会在面板页头显示当前版本，有新版本时显示「新版本」标签，以及带「检查更新」、「更新」按钮和自动更新开关的更新对话框（见[更新](configuration.zh-CN.md#更新)）。从这里发起的更新会安装新包；从已安装的包加载 sideby 的页面会自己换上新版本（前提是它每次检查新代码时，都重新找一次 `sideby` 命令所在的包），面板提示刷新页面。你的页面换上新代码时，要等旧 handler 把手上的请求答完再停掉它（上限以分钟计，不要几秒）：发起更新的那个请求就是其中之一。你的页面自己管理 sideby 版本时传 `updates: false`：面板不再显示任何更新相关内容，并拒绝 `/api/update*`。

`ask: { bridge: 'postMessage' }` 给自己提供 AI 任务的页面用。面板嵌在你页面的 iframe 里时，会隐藏自己的「让 AI 帮我」按钮；每个发起 AI 任务的地方（「问 AI 为什么」「让 AI 修复」、配账号、配终端等）不再打开面板自己的对话框，而是向 `window.parent` 发 `{ type: 'local-tools:ask', version: 1, preset, native: { task, text, context }, text }`，目标 origin 是面板自己的 origin。你的页面显示自己的对话框，用 `sideby ask --spec -` 开始任务，`native` 部分原样传过去（见[命令](commands.zh-CN.md)）；要显示的账号和终端用 `sideby ask --choices --json` 取。包里的 `ai-tasks.json` 列出 sideby 的任务，以及中英两套标题、提示语和示例。不传 `ask`，或面板不在 iframe 里时，面板照旧打开自己的对话框。传其他值会在创建 handler 时抛 `TypeError`。

`<basePath>/icon.svg` 提供 sideby 标志（面板自己的 favicon 用 `<basePath>/favicon.svg`，小尺寸版，只有蓝色那个小伙伴）。在你自己的标签页或菜单里直接引用它，不要另存一份，这样换了新标志，你的页面跟着下一个 sideby 版本更新。

`lang`（`'auto'`、`'en'` 或 `'zh'`）让面板语言和你的页面一致。设为 `'en'` 或 `'zh'` 时，它优先于面板里选过的语言，并隐藏面板「设置」里的语言选项；面板里选过的语言仍然保存着，改回 `'auto'` 后照常生效。`'auto'`（默认）先用面板里选过的语言，再看浏览器语言。其他值会在创建 handler 时抛出 `TypeError`。handler 只在创建时读一次 `lang`：要切换语言，就重新创建 handler。
