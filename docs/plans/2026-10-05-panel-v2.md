# Panel v2 plan (2026-10-05)

Goal: make the Panel usable every day with many accounts. References: cc-switch v4 (interaction details) and magpie's Allowances view (quota-first grouping). Positioning stays as in ADR-0001: no global switching, no credential proxy, no rotation, no credential reads (ADR-0003).

## Scope

### Server data (Runtime, types, handler)

All new fields are optional, so existing family plugins keep working.

| Change | Shape | Notes |
|---|---|---|
| Per-day usage | `UsageResult` (ok) gains `daily?: { date: string; totalTokens: number }[]`, `USAGE_DAYS` entries, oldest first, local dates `YYYY-MM-DD` | Claude and Codex readers already see per-record timestamps |
| Last activity | `UsageResult` (ok) gains `lastActivityAt?: string` (ISO) | newest record time seen by the reader |
| Aliases per account | `PanelAccount.aliases?: string[]` from config `aliases` | lets the page show `cc001` next to `claude:001` |
| Quota teardown route | `POST /api/quota/teardown { family }` | wraps `quotaSetup(family).teardown()`; a write route |
| Schemas | update `schemas/*.json` and `src/cli/json-schemas.ts` where `quota`/`usage` JSON is described | CLI `--json` output stays valid |

Tests: readers produce `daily` and `lastActivityAt` from fixtures (including days with no records = 0); state carries aliases; teardown route needs token, origin and is refused in read-only mode.

### Page (src/panel/page.ts)

1. Header summary: accounts, needing attention, 7-day tokens, soonest quota reset.
2. Toolbar: search (`/` and `⌘F` focus, `Esc` clears), family filter, sort (quota pressure, name, last used), view (list default, cards), used/left toggle, theme (system/light/dark). Preferences in `localStorage` (wrapped in try/catch).
3. Group by family with logo and count; collapsible.
4. Account row: logo, name, ref, aliases, plan, kind, login, health chip (click filters the health list to this account), 5h/7d bars with countdown (`in 2h 30m`, absolute time on hover), stale marker when `observedAt` is old, 7-day mini bars from `daily`, cache hit rate, last used.
5. Row `⋯` menu: copy `sideby run <ref>` (or the alias), copy `sideby login <ref>`, copy directory, check this account, new account like this one (prefills family and API).
6. Toasts (dedupe same text, 2–8 s), refresh shows done/failed, `?` tips for Shared Item, Drift, API account, data age.
7. New account in a dialog: family cards (installed first, logo), name, API toggle, preview of directory and launch command; on success toast and highlight the new row.
8. Quota setup: diff preview, apply, then an Undo action in the toast that calls teardown.
9. Language: English and Chinese, chosen from `navigator.language`, switchable; only Panel text.
10. States: loading skeleton rows, empty, error with retry, disconnected banner (exists), 390px width.

### Not in this round

Cost estimate, session list, drag ordering, API presets, Host versions, in-Panel delete or edit.
