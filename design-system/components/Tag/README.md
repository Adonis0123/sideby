Tags are compact square-cornered labels inside account rows: roles, aliases and problems.

Static rendition of the Panel's `.tag` rules (`components/bundle.css`).

## Use
- `tag` neutral (`surface-2`, `muted`) for roles such as Main; `tag-alias` sets a folder alias in mono, weight 400.
- `tag-ok`, `tag-warn`, `tag-fail` for state; pair with a word, and a 6px dot when it helps scanning.
- 18px tall, 5px radius, 11px weight 600 text. `tag-btn` when clickable.
