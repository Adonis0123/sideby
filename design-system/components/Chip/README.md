Chips are small pill labels for counts, plan types and state beside an account or group.

Static rendition of the Panel's `.chip` rules (`components/bundle.css`).

## Use
- `chip` neutral (`surface-2`, `border`, `muted`) for counts and facts.
- `chip-accent` for the Subscription chip; `chip-ok`, `chip-warn`, `chip-fail` for state, always with a word: color never carries state alone.
- `chip-sm` in dense rows; `chip-btn` when it opens something (adds hover and a focus outline).
- 12px text on a 20px line, radius `chip-radius` (pill).
