# Logos

- `sideby-mark.svg` — the full mark: two buddies side by side, Bai (amber `#f2b35e`, behind, left) and Sai (blue `#3f8fc4` = `logo-fg`, front, right), ink outline `#1e2a44`. Use at 24px and up, on a light ground (`logo-bg`) — keep that tile light in dark mode too. Built from `src/core/brand-mark.ts` (`ICON_SVG`).
- `sideby-favicon.svg` — the small cut below about 24px: Sai alone, body, eyes, cape and crown, redrawn on a 32 grid (`FAVICON_SVG`). Browser tabs, menu bar (18pt).
- `sideby-banner.jpg` — the painted README banner with the same characters (`docs/assets/banner.jpg`). Marketing only, never UI.

Fixed colors: the mark does not follow the Theme. Never recolor Bai, never tilt the pair diagonally, never redraw it.
